# Native acceptance fixtures

These development-only tools qualify retained native CSV fixtures. They are
not imported by PanelFrame and add no dependencies to its normal runtime.

## Check the retained data without native tools

From the repository root:

```sh
python tools/native/check_fixtures.py
```

This standard-library check constructs expected poses using the source CSV
and independently calculated generator transforms. It compares complete
multisets, including labels, sides and component rotations. It does not import
or invoke product discovery. `known_answers.py` derives all transforms from
the fixed source outline dimensions, grid configuration and export origins.
The recorded `expected.json` must agree with that derivation.

## Regenerate using native tools

Required development tools are KiCad **9.0.2**, its matching `pcbnew` Python
module, and KiKit **1.8.1**. Use the official KiCad distribution and the KiKit
package from its official PyPI project. They are not bundled here. The script
rejects other versions, performs no installation, and needs no network.

Use the interpreter supplied with the KiCad bindings and point `KIKIT` at the
isolated KiKit installation. The requested output directory must not exist.

```sh
KIKIT=/path/to/kikit-venv/bin/kikit /usr/bin/python3 tools/native/replay.py \
  --out /tmp/panelframe-native-replay
python tools/native/check_fixtures.py /tmp/panelframe-native-replay
```

The replay creates all source/panel native boards, nine native position CSVs,
three full KiKit presets, the negative component edit, configuration-derived
known answers, a command log and hashes. It runs the independent known-answer
check before returning successfully. Repeated-reference export order and
native UUIDs can vary; byte-identical regeneration is not promised. Compare
pose multisets and transforms, not regenerated byte hashes.

The mixed-source mutations and edited panel are controlled test material,
not a qualified change to the real board. Native tools may warn that the
original board's Electron font is unavailable and substitute a display font;
no external font files are bundled, and font substitution does not change
placement CSV data. See the fixture provenance and preserved MIT notice.
